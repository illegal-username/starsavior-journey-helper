# 스세 여정 도우미

스타 세이비어의 여정 선택지 화면을 기기 안에서 OCR로 읽고, 이벤트명에 맞는 조건·성공 보상·실패 효과를 플로팅 결과창으로 보여 주는 비공식 Android 앱입니다.

- 앱 ID: `helper.journey.starsavior`
- 공개판 버전: `2.2.0` (versionCode 51)
- 최소 Android: 8.0 (API 26)
- 패킷 감시·VPN·접근성 서비스·광고 SDK·자체 사용자 추적 서버 없음
- 화면 이미지와 OCR 결과를 저장하거나 전송하지 않음

개인정보와 권한 처리에 관한 자세한 내용은 [PRIVACY.md](PRIVACY.md)를 확인해 주세요.

## 지원 언어와 언어 선택

앱은 한국어·영어·일본어·중국어 간체/번체·프랑스어·독일어·스페인어·포르투갈어·인도네시아어·베트남어를 지원합니다.
설치 또는 언어 변경 후 **DB 업데이트 / 새 DB 받기**를 눌러 해당 언어의 데이터를 받아 주세요.

- 기본값은 시스템의 첫 번째 언어이며, 미지원 언어는 영어를 사용합니다. 앱의 **게임·도우미 언어**에서 직접 선택하거나 시스템 언어로 되돌릴 수 있습니다. 선택은 저장되며 앱 안내·OCR·DB에 함께 적용됩니다.
- 중국어는 명시된 Hans/Hant 문자를 우선하고, 문자가 없으면 TW/HK/MO는 번체, 그 외는 간체로 선택합니다.
- 선택한 언어에 섞인 영문·숫자도 읽습니다. 게임 설정의 표시 언어와 도우미에서 선택한 언어를 맞춰 주세요.
- 적용 언어가 바뀌면 기존 화면 공유를 종료하고 새 언어의 데이터를 준비합니다. 플로팅 아이콘을 눌러 화면 공유를 다시 허용하세요.
- 안내문에는 게임 파일의 대응 용어를 적용합니다. DB의 이름·선택지·보상 설명도 해당 언어의 원문을 사용합니다.
- OCR 모델은 내장하며, 현재·이전 DB와 업데이트 메타는 언어별로 보관합니다. 한국어의 기존 schema 4 다운로드 DB는 계속 읽을 수 있습니다.

개발 검증은 합성 데이터와 추출 원문 대응을 포함합니다. 영어·일본어·중국어 간체/번체의 기기 시험 결과는 확인했으며, 추가 6개 언어는 원문·매칭·빌드 검증 범위입니다. 태국어·힌디어는 지원하지 않습니다.

## 기존 시험판에서 전환

1.1.0 이하 시험판은 앱 ID와 서명 체계가 다르므로 2.0.0 이상의 공개판으로 덮어쓸 수 없습니다. 기존 플로팅 아이콘을 종료하고 이전 앱을 삭제한 뒤 새 공개판을 설치해야 합니다. 오버레이·알림·화면 공유 권한도 다시 허용해야 합니다. 2.0.0 이상의 공개판 및 build47 시험판 사용자는 같은 운영 키로 서명한 2.2.0 APK를 그대로 설치해 업데이트할 수 있습니다. 내장 DB 시험판에서 전환한 후에는 앱에서 `새 DB 받기`를 눌러 정식 DB를 적용하세요.

## 사용법

1. 앱을 열고 `권한 설정하고 시작`을 누릅니다.
   앱은 로컬 DB를 바로 사용하면서 백그라운드에서 최신 DB 여부를 확인하고, 새 DB가 있으면 준비 상태와 버튼으로 알려 줍니다.
2. `다른 앱 위에 표시`를 허용합니다.
3. Android 화면 공유 창에서 가능하면 `앱 하나 → 스타 세이비어`를 선택합니다.
4. 여정 선택지가 완전히 나타난 뒤 `✦` 아이콘을 누릅니다.
5. 요구 수치가 일치한 이벤트 DB의 한 난이도 조건과 대응되면 해당 조건과 효과만 표시됩니다.
   결과 카드의 선택지 제목은 읽힌 화면에 맞는 일반 또는 단축 문구를 사용합니다. 문구 판별 근거가 부족하면 기본 문구를 표시합니다.
   같은 선택지 문구를 쓰는 여러 아르카나 이벤트는 제목 왼쪽 카드의 비공간 색상 특징까지 비교하며, 근거가 충분하지 않으면 기존처럼 가능한 결과를 모두 표시합니다.
   선택 버튼은 있지만 선택에 따른 분기 효과가 없는 대화 화면에서는 어느 쪽을 골라도 동일하게 진행된다고 안내합니다.
6. 상단 게이지가 보이면 현재 스태미나와 행동 후 예상 스태미나도 함께 표시됩니다.
7. 결과창은 `✦`를 다시 누르거나 `×`를 누를 때까지 유지됩니다.
8. `✦`를 길게 누르면 DB 업데이트 또는 도우미 종료 메뉴가 열립니다.

화면을 잠가 Android가 화면 공유를 종료하더라도 플로팅 아이콘은 유지됩니다. 회색 아이콘을 누르고 시스템 화면 공유를 다시 허용하면 됩니다.

## 권한

| 권한·기능 | 사용 목적 |
| --- | --- |
| 다른 앱 위에 표시 | 플로팅 아이콘과 결과창 |
| MediaProjection | 사용자가 누른 시점의 화면 한 프레임 OCR |
| 포그라운드 서비스·알림 | 화면 공유와 플로팅 아이콘 상태 유지 |
| 인터넷 | 앱 실행 시 경량 DB 버전 확인, 사용자가 실행한 DB 다운로드의 HTTPS 요청 및 ML Kit SDK 통신 가능성(아래 개인정보 안내 참조) |
| 특정 앱 조회 | 스타 세이비어 실행 버튼 제공 |

저장소·카메라·마이크·연락처·계정 권한은 요청하지 않습니다.

## 공개 저장소와 여정 데이터

실제 여정 JSON은 이 저장소와 GitHub 소스 압축 파일에 포함하지 않습니다. 저장소에는 실제 게임 정보가 아닌 `journey_choices.example.json`만 있으며, 공개 소스 빌드는 이 예제 DB로 시작합니다. 앱은 작은 릴리스 정보로 최신 여부를 확인하고, 사용자가 DB 업데이트를 실행하면 호환되는 최신 데이터를 내려받아 해시·형식·출처를 검증한 뒤 적용합니다.
실제 데이터의 권리와 허가 범위는 [DATA_NOTICE.md](DATA_NOTICE.md)를 확인해 주세요.

## 개발 빌드

필요 환경:

- JDK 17
- Android SDK 35

```bash
python3 tools/verify.py --scope android
```

문서·도구만 수정했을 때의 빠른 검증과 선택적 회귀 검증은 [기여 안내](CONTRIBUTING.md#검사)를 참고하세요.

Debug APK는 Android의 표준 debug 키로 서명됩니다. 공개 배포용으로 사용하지 마세요.
